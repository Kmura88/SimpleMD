# mdview

フォルダにためた Markdown ノートを、速く・快適に読むためのデスクトップビューアです。
Rust + [egui](https://github.com/emilk/egui) 製のネイティブアプリで、単体の実行ファイルとして動きます。

## 特長

### 表示

- **GitHub Flavored Markdown** に対応
  - 見出し、強調・太字・取り消し線、リンク、画像
  - ネストしたリスト、タスクリスト
  - 表（列ごとの左・中央・右揃え。表がはみ出すときは横スクロール）
  - 引用、注記（`> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]`）
  - 脚注（参照順に番号を振り直す）、フロントマター（YAML / TOML。折りたたみ表示）
  - 数式（`$...$` は記号に置き換えて行内表示、`$$...$$` は分数・根号・総和・行列などを組版して表示）
  - Mermaid 図（フローチャート・シーケンス図・円グラフ・状態遷移図）
  - `<details><summary>…</summary>…</details>` の折りたたみ
- **コードブロック**: 構文ハイライト（syntect + two-face。TypeScript・TOML・Dockerfile なども対応）付き。長い行は折り返さずに横スクロールし、マウスを乗せるとコピーボタンが出ます。
- **画像**: 相対パス、絶対パス、URL のいずれにも対応（PNG / JPEG / GIF / WebP / BMP / SVG）。幅が足りないときは自動で縮小します。
- **HTML**: `<kbd>` `<b>` `<sup>` `<mark>` `<br>` などのよく使うタグと、`<img>` を含む HTML ブロック（README によくある中央寄せのロゴやバッジ）を表示します。スクリプトは実行しません。
- **日本語**: 段落内の改行は、日本語どうしの間ではスペースを入れずにつなぎます。Shift_JIS のファイルも自動判別して読み込みます。

### ナビゲーション

- **ファイルツリー**: 開いているファイルの場所まで自動で展開します。Markdown を含まないフォルダや、`node_modules` などは表示しません。
- **目次（アウトライン）**: 読んでいる位置を自動でハイライトし、クリックでその見出しへ移動します。
- **リンク**:
  - `other.md` や `../dir/note.md#見出し` のような相対リンクは、アプリ内でそのノートを開きます。
  - `#見出し` は同じページ内の見出しへスクロールします。
  - 外部 URL はブラウザで開きます。
  - `[[ノート名]]` / `[[ノート名#見出し|表示名]]` の Wiki リンクにも対応しています（ファイル名で探します）。
  - ノート内へのリンクにマウスを乗せると、リンク先の内容をポップアップで表示します。
  - Ctrl+クリック / 中クリックで新しいタブに開きます。
- **タブ**: 複数のノートを開いておけます（Ctrl+T / Ctrl+W / Ctrl+Tab）。終了時のタブは次回も復元されます。
- **戻る / 進む**: スクロール位置も含めて履歴を戻れます。マウスのサイドボタンにも対応しています。
- **スクロール位置の記憶**: ファイルごとに読んでいた位置を覚え、開き直すとそこから再開します。
- **バックリンク**: 目次の下に「このノートへリンクしているノート」を一覧表示します。
- **タグ**: フロントマターの `tags:` と本文の `#タグ` を集め、サイドバーの「タグ」から絞り込めます。
- **見出しリンクのコピー**: 見出しにマウスを乗せると 🔗 が出て、`[見出し](ファイル#アンカー)` をコピーできます。

### 検索

- **日本語に強い照合**: どの検索も、ひらがな / カタカナ、全角 / 半角（`ＡＢＣ` / `abc`、`ｶﾞｲﾄﾞ` / `ガイド`）、大文字 / 小文字を区別せずに探します（ページ内検索の「Aa」で完全一致に切り替え）。Shift_JIS のファイルも全文検索の対象です。
- **Ctrl+P**: ファイル名のあいまい検索（例: `gs` で `getting-started.md` が見つかる）。ローマ字でも探せます（`gaido` で `ガイド.md`）
- **Ctrl+F**: ページ内検索。一致箇所をすべてハイライトし、Enter / Shift+Enter で前後へ移動します。
- **Ctrl+Shift+F**: フォルダ内の全ノートを全文検索します（バックグラウンドで実行）。結果をクリックすると、その行の付近へ移動します。

### その他

- **自動再読み込み**: エディタで保存すると、スクロール位置を保ったまま表示を更新します。ファイルの追加・削除もツリーに自動で反映されます。
- **画像の拡大表示**: 画像をクリックすると画面いっぱいに表示します。
- **スライド表示**: F11 で文書を全画面のスライドとして表示します（`---` の区切り線、なければ h1/h2 ごとに 1 枚）。
- **書き出し・印刷**: HTML に書き出せます（コードは色付き、数式・Mermaid も表示）。印刷はブラウザ経由です。
- **外部連携**: エディタで開く（設定でコマンドを指定可能）、フォルダで表示、パスのコピー（⋯ メニュー）。
- **UI の言語**: 日本語 / 英語（OS の言語に自動で合わせます。設定で変更可能）。
- **テーマ**: システム設定に追従・ライト・ダークを切り替えられます（GitHub 風の配色）。
- **文字サイズ・本文の幅**: 変更できます。フォントも自動選択のほか、手動で指定できます。
- **ドラッグ＆ドロップ**: フォルダやファイルをウィンドウに落とすと開きます。
- **前回の状態を復元**: 開いていたフォルダ・ファイル・設定・ウィンドウサイズを次回も引き継ぎます。
- **長い文書でも軽い**: 画面外のブロックは描画を省きます。

## ビルドと実行

[Rust](https://www.rust-lang.org/tools/install) 1.95 以降が必要です。

```bash
cargo build --release
./target/release/mdview ~/notes            # フォルダを開く（README.md / index.md があれば表示）
./target/release/mdview ~/notes/todo.md    # ファイルを開く（親フォルダがツリーになる）
./target/release/mdview                    # 前回の続き（初回はカレントフォルダ）
```

`samples/` に動作確認用のノートがあります。

```bash
cargo run --release -- samples
```

### 動作環境についての注意

- 普段使いは `--release` 付きでビルドしてください。`cargo run`（開発ビルド）でも依存ライブラリは最適化されますが、release の方がさらに軽く動きます。
- Linux では、ファイルのドラッグ＆ドロップに対応するため X11（XWayland）で起動します（描画に使う winit が Wayland でのドロップに未対応のため）。Wayland で起動したい場合は `MDVIEW_BACKEND=wayland` を指定してください。
- **WSL（WSLg）では、Windows のエクスプローラーからのドラッグ＆ドロップは届かないことがあります**（WSLg は Windows と Linux アプリの間のドロップに対応していないとされているため。未検証）。⋯ メニューの「フォルダを開く」（Ctrl+Shift+N）でパスを入力して開いてください。WSL では OS のフォルダ選択ダイアログも使えないため、自動でアプリ内の入力ウィンドウに切り替わります。

- 描画には wgpu（Vulkan / DX12 / Metal）を使います。使えない環境では、自動的に OpenGL で起動し直します。
- **WSL で日本語を入力するには**、WSL 側に日本語入力（IME）が必要です（WSLg では Windows の IME が Linux アプリに届きません）。例（Ubuntu、未検証）:
  ```bash
  sudo apt install fcitx5 fcitx5-mozc
  export XMODIFIERS=@im=fcitx GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx   # ~/.bashrc などに追加
  fcitx5 -d                                                              # 起動（Ctrl+Space で切り替え）
  ```
  入力方式に Mozc が無い場合は `fcitx5-configtool` で追加してください。IME が無くても、貼り付け（Ctrl+V）や、ファイル名検索のローマ字入力は使えます。
- WSL2 では GUI の表示に WSLg が必要です。Ubuntu 20.04 などで起動できない場合は、次を入れてください。
  ```bash
  sudo apt install libegl1 libegl-mesa0 libgl1-mesa-dri libxkbcommon-x11-0
  ```
- WSL では、Windows 側のフォント（`/mnt/c/Windows/Fonts`）も自動で使います。

| キー | 動作 |
|---|---|
| `Ctrl+P` / `Ctrl+O` | ファイルを開く（あいまい検索） |
| `Ctrl+F` | ページ内検索 |
| `Enter` / `Shift+Enter`、`F3` / `Shift+F3` | 次 / 前の一致へ |
| `Ctrl+Shift+F` | 全文検索 |
| `Alt+←` / `Alt+→`、マウスのサイドボタン | 戻る / 進む |
| `Ctrl+B` | サイドバーの表示切替 |
| `Ctrl+Shift+O` | 目次の表示切替 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 文字サイズ 拡大 / 縮小 / リセット |
| `F5` / `Ctrl+R` | 再読み込み（フォルダの再スキャンも行う） |
| `Space` / `Shift+Space`、`PageDown` / `PageUp` | 1 画面分スクロール |
| `J` / `K`、`↓` / `↑` | 少しスクロール |
| `Home` / `End` | 先頭 / 末尾へ |
| `Ctrl+T` / `Ctrl+W` | 新しいタブ / タブを閉じる |
| `Ctrl+Tab` / `Ctrl+Shift+Tab`（`Ctrl+PageDown` / `PageUp`） | 次 / 前のタブ |
| `Ctrl+クリック` / 中クリック | リンクやファイルを新しいタブで開く |
| `F11` | スライド表示（`←` `→` で移動、`Esc` で終了） |
| `Ctrl+E` | HTML に書き出す |
| `Ctrl+Shift+E` | 外部エディタで開く |
| `Ctrl+Shift+N` | フォルダを開く（ダイアログ） |
| `Ctrl+,` | 設定 |
| `Esc` | 検索・ダイアログ・画像の拡大表示を閉じる |

macOS では `Ctrl` の代わりに `Cmd` を使います。

## リリースとバージョン管理

バージョンは `Cargo.toml` の `version`（`メジャー.マイナー.パッチ`）で管理します。変更履歴は `CHANGELOG.md` に書きます。

```bash
scripts/bump-version.sh patch   # 0.1.0 → 0.1.1（不具合修正）
scripts/bump-version.sh minor   # 0.1.0 → 0.2.0（機能追加）
scripts/bump-version.sh major   # 0.1.0 → 1.0.0
# CHANGELOG.md の新しい節に変更内容を書いてから
git add -A && git commit -m "Release v0.1.1" && git push
```

main に push されると GitHub Actions（`.github/workflows/release.yml`）が、そのバージョンのタグがまだ無ければ自動で次を行います。

1. テスト
2. Windows / Linux / macOS（Apple Silicon・Intel）向けにビルド
3. タグ `vX.Y.Z` と GitHub Release を作成し、各 OS 向けの圧縮ファイルと `SHA256SUMS.txt` を添付（本文は CHANGELOG の該当節）

バージョンを上げずに push した場合は、リリースは作られません（`.github/workflows/ci.yml` によるテストだけが走ります）。

## 開発

動作が重いと感じたら、`MDVIEW_PROFILE=1 cargo run --release -- <フォルダ>` で起動すると、起動の内訳・1 フレームの処理時間・時間のかかったブロックが表示されます。

機能とファイルの対応は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) にまとめています。各ファイルは `// ==== 機能: ○○ ====` のコメントで区切ってあります。

```bash
cargo test                    # パーサー・検索・UI 操作（GPU なしのヘッドレス）のテスト
cargo clippy --all-targets
```

| ファイル | 内容 |
|---|---|
| `src/main.rs` | 起動処理、レンダラーのフォールバック、アイコン |
| `src/app.rs` | アプリの状態、ナビゲーション、履歴、キー操作、自動再読み込み |
| `src/ui.rs` | ツールバー、サイドバー、目次、検索バー、ファイル検索、設定、ステータスバー |
| `src/markdown/` | pulldown-cmark のイベントを描画用の文書モデル（AST）に変換 |
| `src/render/` | 文書モデルの描画（行内レイアウト、リンク判定、検索ハイライト、表、画面外の描画省略） |
| `src/highlight.rs` | コードの構文ハイライト（キャッシュ付き） |
| `src/workspace.rs` | フォルダのスキャン、自然順ソート、あいまい検索、全文検索 |
| `src/fonts.rs` | システムフォントの選択（欧文・日本語・等幅・太字） |
| `src/theme.rs` | ライト / ダークの配色 |
| `src/ui_tests.rs` | egui_kittest による UI 操作のテスト |
